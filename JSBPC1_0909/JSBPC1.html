Verziókövető rendszerek és GitHub

Verziókövető rendszerek legfontosabb jellemzői

A verziókövető rendszerek segítségével nyomon követhetjük a fájlok és projektek változásait. Lehetővé teszik a korábbi verziók megtekintését és visszaállítását, a változtatások összehasonlítását, valamint a közös munkát több fejlesztő között.

GitHub használatának legfontosabb parancsai

Local parancsok

  • git init – új Git repository létrehozása
  • git add – fájlok hozzáadása a staging területhez
  • git commit – változtatások mentése egy commitba
  • git status – a repository aktuális állapotának megtekintése
  • git log – korábbi commitok megtekintése

Remote parancsok

  • git remote – távoli repository kezelése
  • git clone – távoli repository letöltése és klónozása
  • git pull – változtatások letöltése a távoli repositoryból
  • git push – változtatások feltöltése a távoli repositoryba
  • git fetch – távoli változtatások lekérése
